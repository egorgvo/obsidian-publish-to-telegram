# Плагин Publish to Telegram

[English](https://github.com/pan4ratte/obsidian-publish-to-telegram/blob/main/README.md) | Русский

Данный плагин позволяет публиковать ваши заметки напрямую в каналы, группы и личные сообщения в Telegram c разными пресетами. Поддерживаются все опции форматирования Telegram, а также вложения медиа и документов. Расширенные настройки публикации позволяют делать запланированные посты, отправлять их сразу в несколько каналов/групп одновременно, и не только.

![](media/plugin-demo-settings.png)


## Фичи

1. Создание пресетов для публикации постов в разные каналы, группы, темы в группах и в личные сообщения.

2. Публикация разными способами: с помощью сочетаний клавиш, палитры команд и контекстных меню.

3. Возможность прикреплять фото, видео, альбомы и документы к постам.

4. Расширенные настройки публикации:

    * Сделать пост, используя сразу несколько пресетов.
    * Сделать пост с уведомлением без звука.
    * Сделать пост с вложениями под текстом сообщения.
    * Запланировать публикацию.
    * Отредактировать уже существующий пост.

5. Публикация заготовленных комментариев в обсуждение поста (или как ответы на сообщение, если пост выкладывается в группу или отправляется пользователю).  

6. Установка пресета по умолчанию для быстрого постинга, а также постинг из палитры команд или с помощью сочетаний клавиш.

7. Возможность включить автоматическое сохранение ссылок на опубликованные посты в свойства заметок.

8. Публикация нескольких постов подряд из одной заметки с помощью специальной команды, разделяющей текст заметки на части.

9. Подробное руководство пользователя с описанием всех функций плагина и опций форматирования прямо в настройках плагина.


## Установка

### Вариант 1: Магазин плагинов Obsidian

1. Находясь в настройках Obsidian, откройте вкладу "Сторонние плагины" и нажмите на кнопку "Обзор".

2. В поисковой строке введите `Publish to Telegram`, нажмите на результат, затем на кнопки "Установить" и "Включить".

Альтернативно, вы можете установить плагин, перейдя на сайт сообщества по ссылке: [https://community.obsidian.md/plugins/publish-to-telegram](https://community.obsidian.md/plugins/publish-to-telegram)

### Вариант 2: плагин BRAT

Если вы хотите протестировать бета-версию плагина или предыдущие обновления, вы можете сделать это с помощью плагина `BRAT`:

1. Из официального магазина плагинов Obsidian установите плагин `BRAT`.

2. В настройках `BRAT` найдите раздел "Beta plugin list" и нажмите на кнопку "Add beta plugin".

3. В появившемся окне вставьте ссылку на репозиторий плагина `Publish to Telegram`: [https://github.com/pan4ratte/obsidian-publish-to-telegram](https://github.com/pan4ratte/obsidian-publish-to-telegram)

4. В пункте "Select a version" выберите нужную версию и нажмите на кнопку "Add plugin". Плагин автоматически установится и будет готов для использования.


## Руководство пользователя

### Пресеты

Для публикации заметок в Telegram необходимо настроить пресет.

1. Находясь в настройках плагина, авторизуйтесь в свой аккаунт и убедитесь, что у вас есть соответствующие права для постинга в целевые каналы/группы. Доступна авторизация по номеру телефона или с помощью QR.

2. Создайте пресет и нажмите на поле поиска для загрузки списка чатов. Также, `@username` или `ID` можно ввести вручную. Узнать `ID` любого пользователя, канала, группы или бота можно у [@userinfobot](https://t.me/userinfobot).

3. Добавьте в пресет один или несколько целевых каналов, групп, тем в группах, чатов или ботов.

Теперь вы можете публиковать заметки в Telegram, используя имя вашего пресета через палитру команд, с помощью контекстного меню заметки или с помощью сочетаний клавиш.

### Скрытие текста из поста

Кроме форматирования, которое будет отражено в посте в Telegram, вы можете использовать синтаксис комментариев `<!-- скрытый текст -->` или `%% скрытый текст %%`, чтобы добавлять в заметки информацию, которая не будет включена в содержание поста при его публикации.

### Разделение заметки на несколько постов

Также, вы можете использовать специальную команду `<!-- \split -->` или `%% \split %%` для того, чтобы разделить текст своей заметки на несколько отдельных постов. При использовании команды, плагин опубликует все посты одновременно. Вложения (см. далее), в том числе и заготовленные комментарии, должны находится до специальной команды, обозначающей конец поста.    

### Вложения

Поддерживаются вложения в виде медиа, альбомов (групп медиа) и документов. Чтобы прикрепить файл к посту, используйте синтаксис любой из стандартных опций встраивания в Obsidian:

`![[файл-какой-то-книги.pdf]]`

`![](файл-какой-то-картинки.jpg)`

`!(файл-какого-то-видео.mp4)[]`

Также, вы можете встраивать внешние файлы из интернета:

`![](https://obsidian.md/картинка.png)`

Форматы, поддерживаемые на данный момент:

| Расширение                                         | Тип вложения    |
| -------------------------------------------------- | --------------- |
| `.jpg`, `.jpeg`, `.png`, `.webp`                   | Фото / Альбом   |
| `.gif`                                             | Анимация        |
| `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`            | Видео / Альбом  |
| `.pdf`                                             | Документ        |

### Заготовленные комментарии

Вы можете заготовить один или несколько комментариев для вашего поста, которые появятся сразу после публикации в его обсуждении. Для использования этой опции:

1. В настройках плагина включите функцию "Считать .md-вложения комментариями к посту".

2. Чтобы заготовить комментарий к посту, используйте синтаксис встраивания `![[файл-комментария]]`. Только файлы с расширением .md считаются комментариями.

Несколько примечаний:

* Если комментарий к посту будет опубликован в группе или в личных сообщениях, то он отобразится как обычный ответ на сообщение.

* Если вы используете функцию разделения заметок на несколько постов (см. выше), вы можете заготовить комментарии для каждого из них. Для этого расположите эти вложения перед соответствующим маркером.

* Обратите внимание, что комментарии публикуются с небольшой задержкой.

### Расширенные настройки публикации

Вы можете вызывать окно расширенных настроек публикации через палитру команд (`Ctrl + P`), введя "Publish to Telegram: Опубликовать с расширенными настройками". В этом окне настроек вы можете:

* Сделать пост, используя сразу несколько пресетов.

* Сделать пост с уведомлением без звука.

* Сделать пост с прикреплёнными медиа под текстом сообщения.

* Запланировать публикацию.

* Отредактировать уже существующий пост. Ссылки на посты хранятся в свойстве `telegram_links`, которое заполняется автоматически если включена соответствующая функция в настройках, а также его можно создать и заполнить вручную.

### Лимиты

Стандартные лимиты для постов в Telegram применяются к лимитам на количество символов на пост, лимитам по размерам прикреплённых файлов на пост, и т.д. Больше об этом: [https://limits.tginfo.me/](https://limits.tginfo.me/)

Также, не могу не порекомендовать другой мой плагин [Advanced Word Count](https://community.obsidian.md/plugins/advanced-word-count), который позволяет создавать детальные пресеты для подсчёта слов в заметках и обладает на порядок более широкими возможностями по сравнению со стандартным счётчиком слов Obsidian. Этот плагин можно настроить таким образом, чтобы он подсчитывал символы именно так, как их подсчитывает Telegram.
